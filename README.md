## 📌 Tentang Project

**Aplikasi Biodata** adalah aplikasi desktop sederhana yang dibuat menggunakan **Python** dan **Tkinter** untuk mengelola serta menampilkan data biodata pengguna melalui antarmuka grafis (GUI).

Project ini dibuat sebagai bagian dari pembelajaran pemrograman Python, khususnya dalam penerapan **GUI, validasi input, event handling, file handling, dan logging**.

---

## ✨ Fitur

- 🔐 **Login System**
  - Username dan password
  - Remember username
  - Show/hide password

- 👤 **Form Biodata**
  - Nama lengkap
  - NIM
  - Jurusan
  - Email
  - Nomor telepon
  - Tanggal lahir
  - Alamat
  - Jenis kelamin

- ✅ **Validasi Input**
  - Validasi nama
  - Validasi NIM
  - Validasi format email
  - Validasi nomor telepon Indonesia
  - Validasi tanggal lahir
  - Mencegah tanggal lahir di masa depan

- 🎨 **Tema Aplikasi**
  - Tema berdasarkan pengguna
  - Tampilan GUI yang sederhana dan responsif

- 💾 **Penyimpanan Data**
  - Menampilkan hasil biodata
  - Menyimpan hasil ke file `.txt`
  - Mencatat waktu penyimpanan

- ⌨️ **Keyboard Shortcut**
  - `Shift + Enter` untuk mengirim data
  - `Enter` untuk berpindah antar-field

- 📝 **Logging**
  - Mencatat aktivitas penting aplikasi
  - Mencatat proses login dan penyimpanan data
